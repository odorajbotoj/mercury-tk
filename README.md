# mercury-tk

A **simple** (and maybe **unsafe**) ui client for [Mercury HF Modem](https://github.com/Rhizomatica/mercury)

written in `Python3` with `tkinter` , `PIL` , `numpy` , `websocket-client` ...

by BG4QBF

## Features

+ set Mercury audio and radio devices
+ CQ and connect
+ chat and send file
+ broadcast
+ simple chat history save
+ simple QSO LOG save (ADIF)
+ waterfall
